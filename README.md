# BYOK-OS

> **BYOK-OS** (*Bring Your Own Key Operating System*) is an open-source, GUI-driven workspace designed to connect seamlessly with 100+ Large Language Models (LLMs) using your own API keys.

---

### Coming Soon

BYOK-OS is currently under active development. Stay tuned for early releases, setup documentation, and architecture previews.

### Planned Features
* **Bring Your Own Key (BYOK):** Retain complete control over your credentials and cloud billing.
* **Broad Model Support:** Compatibility with 100+ LLMs and model providers (OpenAI, Anthropic, Gemini, local runtimes like Ollama, and more).
* **Intuitive GUI:** Desktop-grade interface for managing agents, prompt chains, and model switches without CLI overhead.
* **Privacy First:** Direct client-to-provider connections with local key storage.
